# LTX-2.3 v1.4 Q4 Salad

`workflows/` に単一段I2Vと二段階T2V/I2Vを配置しています。イメージのビルド時にComfyUIの保存済みワークフローへコピーします。

起動時はv1.4の5ファイルと公式x2 upscalerを取得します。upscalerは固定revisionとSHA-256で検証します。

操作方法と二段階の初期値は [Vastモデルの説明](../../../vast/models/ltx-2.3-uncensored-v1.4-q4/README.md#二段階-t2v--i2v) を参照してください。

既存のSHAタグにはこの修正は入りません。新しいSHAタグのイメージへ更新してください。課金禁止が有効な間は起動・生成しません。
